```bash

git clone https://github.com/evilscriptbull/cadLeader.git
cd cadLeader

# 2. Install dependencies
npm install

# 3. Start application
npm start

# 4. Open browser
# Main Dashboard: http://localhost:3000/
# Point Cloud Viewer: http://localhost:3000/pointcloud.html
```

```cmd

setup.bat
```

#### **Linux/Mac Users**
```bash
# Run setup script
chmod +x setup.sh
./setup.sh
```
